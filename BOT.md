# NEXDEV Telegram bot + .env

Barcha o'zgaruvchan nomlar `.env` faylida.

## Sozlash

1. `@BotFather` → `/newbot`
2. `.env` ni ochib yozing:

```
TELEGRAM_USERNAME=sizning_username
TELEGRAM_BOT_TOKEN=123456:AA...
TELEGRAM_ADMIN_CHAT_ID=123456789
PHONE=+998 91 708 09 92
```

3. Botga `/start` yuboring
4. `php get_chat_id.php` — Chat ID ni oling va `.env` ga yozing
